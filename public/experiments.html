Lists experiments via the config API (GET /experiments, bearer-authed). Click a row to load its results (GET /results/:id, public).

New experiment

Creates via POST /experiments. Set each variant's "% traffic" to control its share of the bucket space — they must add up to 100%. Mark a variant "Generate with LLM" to have its copy written server-side by the Anthropic API instead of typing it yourself — the request blocks until generation finishes, so this can take a few seconds.

Variants

Edit allocation

Only traffic allocation can be changed here (PATCH /experiments/:id/allocation). Variant names/IDs/content and adding or removing a variant aren't editable this way — that's a new experiment (new salt), per DESIGN.md §2. Since the server only allows moving one shared boundary between adjacent variants per call, a change here may be sent as several sequential requests automatically.
